# Agent research protocol

Goal: recommend one BTC-USD Coinbase Exchange forecast for 20 November 2026 21:00 UTC using only inputs available by 13 November 2026 12:00 UTC. Scoring reference is the 20:59 one-minute candle close. Never trade or request credentials.

Permitted tools: public read-only market HTTP requests, local snapshot inspection, Python calculation/testing, artifact authoring. Inspect the assignment first. Preserve genuine command inputs, stdout, stderr, execution status, source hashes, decisions and limitations. Never reconstruct a fictional transcript. A script run alone is not agent evidence.

Construct seven-day momentum and compare regression with no-change forecasts at strictly earlier origins, matching the 177-hour horizon. Exclude training labels not available at each origin. Evaluate 3/7/14-day sensitivity and failures. Inspect output before recommending a model; prefer the benchmark if complexity lacks evidence. Independently verify arithmetic and time boundaries. Disclose retrospective availability assumptions. Stop finalisation for human review of the concrete numerical forecast. Only human-approved results may enter a frozen submission.
